# Google Sheets form delivery

Один Google Apps Script приймає перевірені заявки від Cloudflare Worker і записує їх у сім таблиць: школа, бадмінтон, три товари, СВОЇ club і CYM Hub.

Порядок колонок після дати надсилання для СВОЇ club: дата зустрічі, вік, ім’я латиницею, інша активність, телефон, Telegram, Instagram, email, ім’я для рахунку, дозвіл на зйомку, дозвіл на використання матеріалів.

Порядок колонок після дати надсилання для CYM Hub: дата візиту, ім’я латиницею, ім’я кирилицею, вік, телефон, Telegram, email, ім’я для рахунку, дозвіл на зйомку, дозвіл на використання матеріалів.

## 1. Опублікувати Apps Script

1. Під обліковим записом, який має право редагувати всі сім таблиць, відкрийте
   [script.google.com](https://script.google.com/) і натисніть **New project**.
   Використовуйте окремий проєкт у своєму Google Drive, а не скрипт, прив’язаний
   до чужої таблиці: так власник проєкту гарантовано матиме право на розгортання.
2. Замініть вміст `Code.gs` кодом із файлу `Code.gs` у цій папці та збережіть проєкт.
3. У списку функцій угорі виберіть `testAuth`, натисніть **Run** і підтвердьте
   запитані Google дозволи. Функція лише перевіряє доступ до всіх семи таблиць
   і потрібних аркушів, не додаючи та не змінюючи дані. `doPost` вручну не запускайте.
4. У **Project Settings → Script Properties** додайте властивість `API_TOKEN`. Значення має бути випадковим секретом довжиною щонайменше 24 символи.
5. Натисніть **Deploy → New deployment → Web app**.
6. Встановіть **Execute as: Me** і **Who has access: Anyone**, потім підтвердьте доступ до таблиць.
7. Скопіюйте URL розгортання, який закінчується на `/exec`.

Якщо Google Workspace не показує варіант **Anyone** або забороняє розгортання,
це обмеження адміністратора домену. У такому разі створіть проєкт під особистим
Google-акаунтом і надайте цьому акаунту право **Editor** у всіх семи таблицях.

## 2. Додати секрети Cloudflare Worker

У Cloudflare Dashboard відкрийте Worker `cym-ee` → **Settings → Variables and Secrets** і додайте як зашифровані секрети:

- `APPS_SCRIPT_URL` — URL розгортання Apps Script `/exec`;
- `APPS_SCRIPT_TOKEN` — те саме значення, що й `API_TOKEN` у Script Properties.

Або задайте їх із термінала (значення вводяться приховано й не зберігаються в історії команд):

```bash
npx wrangler secret put APPS_SCRIPT_URL
npx wrangler secret put APPS_SCRIPT_TOKEN
```

Після додавання секретів повторно розгорніть Worker. Секрети не потрібно додавати до GitHub або вихідного коду.

Якщо Apps Script не відповідає, форма автоматично відкриває підготовлений лист на `cym@ukraine.ee`.
