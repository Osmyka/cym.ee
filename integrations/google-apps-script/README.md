# Google Sheets form delivery

Один Google Apps Script приймає перевірені заявки від Cloudflare Worker і записує їх у дев’ять таблиць: школа, бадмінтон, три товари, СВОЇ club, CYM Hub, малювання і кіноклуб.

Порядок колонок після дати надсилання для кіноклубу: дата сеансу, ім’я учасника латиницею, вік, ім’я представника латиницею, телефон, email, згода на обробку даних, згода на зйомку, згода на використання фото та відео. Згода на дані — «Так». Згоди на зйомку та використання фото необов’язкові: позначка дає «Так», без неї записується «Ні». Для учасника від 18 років колонка представника лишається порожньою.

Порядок колонок після дати надсилання для малювання: дата заняття, ім’я дитини латиницею, вік, ім’я одного з батьків латиницею, телефон, email, згода на обробку даних, згода на зйомку, згода на використання фото та відео. Згода на дані записується як «Так». Згоди на зйомку та використання фото й відео необов’язкові: позначена згода — «Так», без позначки — «Ні».

Порядок колонок після дати надсилання для СВОЇ club: дата зустрічі, вік, ім’я латиницею, інша активність, телефон, Telegram, Instagram, email, ім’я для рахунку, дозвіл на зйомку, дозвіл на використання матеріалів.

Порядок колонок після дати надсилання для CYM Hub: дата візиту, ім’я латиницею, ім’я кирилицею, вік, телефон, Telegram, email, ім’я для рахунку, дозвіл на зйомку, дозвіл на використання матеріалів.

## Оновити вже опублікований скрипт

Не створюйте новий проєкт і не робіть нове розгортання з новим URL. Секрети Worker уже вказують на поточну адресу `/exec`.

1. Відкрийте наявний проєкт Apps Script.
2. Надайте обліковому запису, від імені якого виконується скрипт, право **Editor** у [таблиці малювання](https://docs.google.com/spreadsheets/d/1UInpB8dz0tmYG7kWVnl8uo2ZII-FBr6hfY5Z-8YLNFE/edit) і в [таблиці кіноклубу](https://docs.google.com/spreadsheets/d/1W7dx2s5yq27-xy2AMYnr-Jx3ZoJPNDPGNRAFS1ts_9M/edit). В обох аркуш має називатися `Аркуш1`. Перша колонка — дата надсилання, її заповнює скрипт; далі йдуть дев’ять колонок із форми.
3. Замініть увесь вміст `Code.gs` кодом із файлу `Code.gs` у цій папці та збережіть. Властивість `API_TOKEN` не змінюйте.
4. У списку функцій виберіть `testAuth`, натисніть **Run** і підтвердьте доступ, якщо Google його запитає. Функція лише відкриває всі дев’ять таблиць і нічого не записує. `doPost` вручну не запускайте.
5. Натисніть **Deploy → Manage deployments**, біля чинного вебзастосунку натисніть олівець, у полі **Version** виберіть **New version** і натисніть **Deploy**. Адреса `/exec` лишається тією самою, тож секрети Worker змінювати не потрібно.

## 1. Опублікувати Apps Script уперше

1. Під обліковим записом, який має право редагувати всі дев’ять таблиць, відкрийте
   [script.google.com](https://script.google.com/) і натисніть **New project**.
   Використовуйте окремий проєкт у своєму Google Drive, а не скрипт, прив’язаний
   до чужої таблиці: так власник проєкту гарантовано матиме право на розгортання.
2. Замініть вміст `Code.gs` кодом із файлу `Code.gs` у цій папці та збережіть проєкт.
3. У списку функцій угорі виберіть `testAuth`, натисніть **Run** і підтвердьте
   запитані Google дозволи. Функція лише перевіряє доступ до всіх дев’яти таблиць
   і потрібних аркушів, не додаючи та не змінюючи дані. `doPost` вручну не запускайте.
4. У **Project Settings → Script Properties** додайте властивість `API_TOKEN`. Значення має бути випадковим секретом довжиною щонайменше 24 символи.
5. Натисніть **Deploy → New deployment → Web app**.
6. Встановіть **Execute as: Me** і **Who has access: Anyone**, потім підтвердьте доступ до таблиць.
7. Скопіюйте URL розгортання, який закінчується на `/exec`.

Якщо Google Workspace не показує варіант **Anyone** або забороняє розгортання,
це обмеження адміністратора домену. У такому разі створіть проєкт під особистим
Google-акаунтом і надайте цьому акаунту право **Editor** у всіх дев’яти таблицях.

## 2. Додати секрети Cloudflare Worker

У Cloudflare Dashboard відкрийте Worker `cym-ee` → **Settings → Variables and Secrets** і додайте як зашифровані секрети:

- `APPS_SCRIPT_URL` — URL розгортання Apps Script `/exec`;
- `APPS_SCRIPT_TOKEN` — те саме значення, що й `API_TOKEN` у Script Properties.

Або задайте їх із термінала (значення вводяться приховано й не зберігаються в історії команд):

```bash
npx wrangler secret put APPS_SCRIPT_URL
npx wrangler secret put APPS_SCRIPT_TOKEN
```

Після додавання секретів повторно розгорніть Worker. Секрети не потрібно додавати до GitHub або вихідного коду.

Якщо Apps Script не відповідає, форма автоматично відкриває підготовлений лист на `cym@ukraine.ee`.
